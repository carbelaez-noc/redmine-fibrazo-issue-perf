# Fibrazo Issue Perf

Lazy-load **split** del formulario en issue show.

- **Siempre en HTML:** notas + adjuntos (`filedrop`) → pegar capturas con Redmine nativo.
- **AJAX:** propiedades / custom fields (`GET /issues/:id/lazy_edit_attributes`).

Ver guía completa: [`docs/OPTIMIZACION_VISTAS_REDMINE.md`](../../../../docs/OPTIMIZACION_VISTAS_REDMINE.md) (repo helpdesk).
